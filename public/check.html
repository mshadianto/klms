Troubleshooting Cepat

Jika aplikasi utama tidak terbuka tetapi halaman ini terbuka:
  • Hard reload: Ctrl + Shift + R (Windows) atau Cmd + Shift + R (Mac)
  • Coba private/incognito mode untuk eliminasi cache & extension
  • Disable browser extension AdBlocker / antivirus web filter
  • Coba browser lain (Chrome ↔ Edge ↔ Firefox)
  • Coba dari jaringan lain (hotspot HP) untuk eliminasi firewall kantor
Jika semua URL di atas gagal:
  • Kemungkinan firewall korporat memblokir GitHub Pages / Cloudflare
  • Hubungi IT untuk whitelist *.mshadianto.id dan *.github.io
  • Lapor ke sopian.hadianto@gmail.com dengan info browser, OS, jaringan, dan screenshot error
